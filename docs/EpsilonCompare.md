**Epsilon(ε) 기반 비교'**는 프로그래밍에서 **부동 소수점(실수) 데이터를 비교할 때 발생하는 오차를 해결하기 위한 방법**

---

### 1. 왜 그냥 비교(`==`)하면 안 되나요?

컴퓨터는 숫자를 2진수로 저장합니다. 그런데 `0.1`이나 `0.2` 같은 10진수 소수는 2진수로 변환하면 무한 소수가 되어버려요. 그래서 아주 미세한 **정밀도 오차**가 발생합니다.

**예시 (Python):**
```python
a = 0.1 + 0.2
b = 0.3

print(a == b)  # 결과: False
print(a)       # 결과: 0.30000000000000004
```
위 코드에서 보듯 `a`는 정확히 `0.3`이 아니기 때문에 `==` 연산자로 비교하면 `False`가 나옵니다.

---

### 2. 에프실론(Epsilon) 기반 비교란?

두 수의 차이가 **"매우 작은 값(Epsilon)"**보다 작으면, 두 수가 사실상 같다고 간주하는 방식입니다.

*   **공식:** `|a - b| < ε` (a와 b의 차이의 절대값이 에프실론보다 작으면 같다!)

---

### 3. 코드 예제

#### Python 예제
파이썬에서는 직접 작은 값을 설정하거나, 표준 라이브러리를 사용할 수 있습니다.

```python
import math

a = 0.1 + 0.2
b = 0.3

# 1. 직접 에프실론 설정 (보통 1e-9 등 사용)
epsilon = 1e-9
if abs(a - b) < epsilon:
    print("두 수는 같습니다! (직접 비교)")

# 2. math.isclose() 함수 사용 (권장 방법)
if math.isclose(a, b):
    print("두 수는 같습니다! (math.isclose 사용)")
```

#### C++ 예제
C++에서는 `std::numeric_limits`를 활용해 시스템이 제공하는 최소 오차 범위를 알 수 있습니다.

```cpp
#include <iostream>
#include <cmath>   // abs()
#include <limits>  // epsilon()

int main() {
    double a = 0.1 + 0.2;
    double b = 0.3;

    // 아주 작은 값(epsilon) 설정
    double epsilon = std::numeric_limits<double>::epsilon();

    if (std::abs(a - b) < epsilon) {
        std::cout << "두 수는 같습니다!" << std::endl;
    }

    return 0;
}
```

### 4. 요약 및 팁

1.  **부동 소수점은 `==`로 비교하지 마세요.** 오차 때문에 예상치 못한 결과가 나올 수 있습니다.
2.  **절대값의 차이**가 내가 정한 아주 작은 수(`epsilon`)보다 작은지 확인하세요.
3.  **주의점:** 숫자가 매우 커지거나 작아지면 상대적인 오차도 변하므로, 실무에서는 `math.isclose()`처럼 **상대 오차**까지 고려된 함수를 쓰는 것이 가장 안전합니다.
