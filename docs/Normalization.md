데이터 전처리 단계에서 아주 중요한 **정규화(Normalization)**와 **표준화(Standardization)**

두 개념 모두 데이터의 **'스케일(범위)'을 조정**하여 모델이 더 잘 학습하게 만드는 것이 목적입니다.

---

### 1. 정규화 (Normalization)
정규화는 데이터의 범위를 **0과 1 사이**로 맞추는 작업입니다. (Min-Max Scaling이라고도 불러요.)

*   **공식:** $X_{new} = \frac{X - X_{min}}{X_{max} - X_{min}}$
*   **특징:**
    *   모든 데이터가 0~1 사이의 값을 가집니다.
    *   데이터의 최소값($min$)과 최대값($max$)을 알 때 유용합니다.
*   **언제 쓸까요?**
    *   데이터의 분포가 균등할 때 사용하면 좋습니다.
    *   이미지 처리(픽셀 값 0~255를 0~1로 변환)에서 자주 쓰입니다.
*   **주의점:** 이상치(Outlier)가 있으면 데이터가 좁은 범위로 몰릴 수 있습니다.

### 2. 표준화 (Standardization)
표준화는 데이터의 **평균을 0, 표준편차를 1**로 만드는 작업입니다. (Z-score Normalization이라고도 불러요.)

*   **공식:** $X_{new} = \frac{X - \mu}{\sigma}$ ($\mu$: 평균, $\sigma$: 표준편차)
*   **특징:**
    *   데이터가 정규분포(종 모양)를 따르도록 변환됩니다.
    *   값의 범위에 제한이 없습니다(0~1을 넘을 수 있음).
*   **언제 쓸까요?**
    *   데이터에 **이상치(Outlier)**가 포함되어 있을 때 정규화보다 훨씬 안정적입니다.
    *   많은 머신러닝 알고리즘(SVM, 선형 회귀 등)에서 기본적으로 권장됩니다.

---

### 3. 한눈에 비교하기

| 구분 | 정규화 (Normalization) | 표준화 (Standardization) |
| :--- | :--- | :--- |
| **범위** | 0 ~ 1 사이 | 제한 없음 (평균 0 중심) |
| **이상치 영향** | 매우 민감함 | 비교적 덜 민감함 |
| **주요 목적** | 모든 특성의 척도를 동일하게 맞춤 | 데이터를 정규분포 형태로 만듦 |

---

### 4. 코드 예시 (Python)

```python
import numpy as np

data = np.array([10, 20, 30, 40, 50])

# 1. 정규화 (Min-Max)
normalization = (data - np.min(data)) / (np.max(data) - np.min(data))
print(f"정규화 결과: {normalization}") 
# [0.   0.25 0.5  0.75 1.  ]

# 2. 표준화 (Z-score)
standardization = (data - np.mean(data)) / np.std(data)
print(f"표준화 결과: {standardization}")
# [-1.414 -0.707  0.     0.707  1.414]
```

### 💡 왜 이 작업이 필요한가요?
딥러닝 모델은 입력 데이터의 스케일이 너무 다르면(예: 나이는 0~100, 연봉은 0~1억), 학습 속도가 매우 느려지거나 특정 변수에만 치우쳐 학습될 수 있습니다. 정규화나 표준화를 해주면 **경사하강법(Gradient Descent) 시 최적의 값을 더 빠르고 안정적으로 찾을 수 있어요!**

라벨이 여러 형식으로 뒤섞여 있는 것을 일관된 형식으로 바로잡는 작업은 주로 다음과 같은 용어로 불립니다.

### 1. 데이터 정제 (Data Cleaning / Cleansing)
가장 포괄적인 용어로, 데이터셋에서 잘못된 정보, 중복된 데이터, 형식이 일치하지 않는 데이터를 수정하거나 제거하는 전체 과정을 의미합니다.

### 2. 라벨 정규화 (Label Normalization)
텍스트 데이터의 대소문자 통합, 띄어쓰기 제거, 특수문자 처리 등을 통해 서로 다른 형태의 라벨을 하나의 표준적인 형태로 통일하는 구체적인 작업입니다.
*   예: `apple`, `Apple`, `APPLE` → `apple`로 통일

### 3. 데이터 표준화 (Data Standardization)
데이터의 명칭이나 형식을 미리 정해진 기준(표준)에 맞추는 작업입니다. 여러 소스에서 수집된 데이터의 라벨명이 다를 때(예: '남성', '남자', 'M' → 'Male') 이를 하나로 맞추는 과정을 포함합니다.

### 4. 정형화 (Canonicalization)
여러 가지 표현이 가능한 데이터를 하나의 '기본적이고 결정적인 형태(Canonical form)'로 변환하는 과정을 뜻하는 컴퓨터 과학 용어입니다.

**요약:**
일반적으로는 **데이터 정제**라고 부르며, 라벨의 형식을 맞추는 구체적인 맥락에서는 **라벨 정규화** 또는 **라벨 표준화**라는 용어를 사용합니다.
