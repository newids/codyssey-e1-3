$O(N^2)$은 시간 복잡도를 나타내는 빅오 표기법 중 하나로, 입력 데이터의 크기($N$)의 제곱에 비례하여 연산 횟수가 증가하는 상태를 의미합니다.

### 1. 특징
*   **데이터 비례 관계**: 입력 데이터가 10배 늘어나면 연산 횟수는 100배($10^2$)로 늘어납니다.
*   **효율성**: 데이터의 양이 많아질수록 실행 시간이 급격히 증가하여 대규모 데이터 처리에는 부적합합니다.
*   **발생 조건**: 주로 중첩된 반복문(Nested Loop)이 두 번 사용될 때 나타납니다.

### 2. 코드 예시 (Python)
입력 리스트의 모든 요소를 서로 한 번씩 비교하는 경우입니다.

```python
def example_quadratic(arr):
    n = len(arr)
    for i in range(n):          # 첫 번째 반복문 (N번)
        for j in range(n):      # 두 번째 반복문 (N번)
            print(arr[i], arr[j]) # 총 N * N 번 실행
```

### 3. 대표적인 알고리즘
*   **정렬 알고리즘**: 버블 정렬(Bubble Sort), 선택 정렬(Selection Sort), 삽입 정렬(Insertion Sort).
*   **행렬 연산**: 두 행렬의 곱셈(기본적인 방식).
*   **그래프 알고리즘**: 인접 행렬을 이용한 그래프 탐색.

### 4. 데이터 크기에 따른 연산 횟수 예시
*   $N = 10$ 일 때, 연산 횟수 $\approx 100$
*   $N = 1,000$ 일 때, 연산 횟수 $\approx 1,000,000$
*   $N = 100,000$ 일 때, 연산 횟수 $\approx 10,000,000,000$ (약 100억 번)
